Arquitetura de Cache
Diferenca fundamental entre os bancos que impacta os resultados

MariaDB (InnoDB)

Buffer Pool512MB (innodb_buffer_pool_size)
Cache externoNao (O_DIRECT)
ComportamentoBuffer pool e tudo que tem
Working set > 512MBVai a disco → alto IO wait
Slow query log> 2s

PostgreSQL

Shared Buffers128MB (shared_buffers)
Cache externoSim (page cache do SO)
effective_cache_size4GB (padrao)
ComportamentoCache duplo: shared_buffers + SO
Slow query log> 2s (log_min_duration_statement)
